Factorial Calculator

A simple Python program that calculates the factorial of a given number using an iterative approach.

Description

This project computes the factorial of a positive integer n (denoted n!), which is the product of all positive integers less than or equal to n. It's a lightweight, easy-to-understand implementation ideal for learning basic Python loops and arithmetic operations.

Features
Calculates the factorial of a number using a simple for loop
Minimal, dependency-free implementation
Easy to read and modify for educational purposes
Requirements
Python 3.x

No external libraries or packages are required.

Installation
Clone this repository:
bash
   git clone https://github.com/your-username/your-repo-name.git
Navigate into the project directory:
bash
   cd your-repo-name
Usage

Run the script using Python:

bash
python factorial.py

By default, the script calculates the factorial of 5. To calculate the factorial of a different number, open factorial.py and change the value of the n variable:

python
n = 5  # change this to any non-negative integer
Example

Input:

python
n = 5

Output:

120

Since 5! = 5 × 4 × 3 × 2 × 1 = 120.
